# スマホ・タブレットのチャート表示

## 実装計画

- 1280px未満をスマホ・タブレット表示とし、銘柄情報、最新足の始値・高値・安値・出来高、日付と時間足の配置を統一する。
- 株価と出来高は共通の時間軸を持つ別ペインとし、高さを5:1にする。価格軸の初期範囲固定を維持する。
- 768px以上では銘柄リストの常設・開閉を維持する。
- 専用worktreeと `codex/mobile-tablet-volume-panes` ブランチで実装し、回帰テストと実画面で確認する。

## 検証

- `npm run verify` 成功（API型同期・lint・型チェック・302テスト・本番ビルド）。Node.js 24.20.0 / npm 12.0.2。
- Chromeで390×844、820×1180、1180×820、1440×1000を確認。スマホへ戻した際も別ペインに復元され、横方向のはみ出しとJavaScript例外はなし。
- 表示確認はローカルアプリにブラウザ側でサンプルAPIレスポンスを与えて実施。実データの取得や実機タッチ操作の検証とは区別する。
